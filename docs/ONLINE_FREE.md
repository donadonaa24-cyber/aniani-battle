# 無料オンライン招待対戦（PCブラウザ試験版）

## 遊び方

1. ポータルの `games/anibato/` でゲームを読み込み、「音を有効にして開演！」を押す。
2. 上部の「オンライン対戦」から自分の3人を順番に選ぶ。同チーム内の重複は不可。
3. 片方が部屋を作成し、招待コードを対戦相手にだけ渡す。相手はコードを貼り付けて参加する。
4. 両者の「対戦の準備完了」で開始。どちらもP1のキー／ゲームパッドを使う。
5. 結果画面では両者の決定で次へ。引き分けは同じ出場者で再戦。先に2勝するとチーム決着。
6. 「対戦を終了」で切断する。切断・同期不一致を勝利や報酬として処理しない。

## 課金を増やさない構成

既存の `aniani-common` プロジェクトをFree/Nanoのまま利用する。新しい有料プラン・有料アドオン・TURN中継・Storage配信を追加しない。Supabaseは初回の接続情報交換だけで、ゲーム本体・画像はGitHub Pagesから配信する。対戦中の入力はWebRTCのDataChannelで直接送受信する。

- 接続待ち部屋：同時4室、UTC日付ごとに80室、1室120秒。1室の接続情報読み取りは48回まで、クライアントは3秒間隔で38回まで。
- 接続後のセッション：20分まで。入力は約35msごとにまとめ、1パケット8KiB・毎秒120パケット・送信待ち64KiBを上限とする。
- ゲーム入力：60Hz、6フレームの入力遅延。入力が欠けたら両者のシミュレーションを待たせ、8秒届かなければ終了する。推測の中立入力で先へ進めない。
- 状態照合：120入力フレームごとの診断ハッシュ。不一致時は停止する。暗号的な不正対策やサーバーによる勝敗認証を保証するものではない。
- 試合ごとに通信番号を進め、引き分け再戦・チーム再戦でも前試合のパケットを使わない。
- 超過・接続不可時は案内して終了し、有料中継へ切り替えない。

Freeは従量課金で自動請求されるプランではない。上限到達時は接続できなくなる可能性がある。同居するコイン・他作品の利用枠も共有するため、無料枠が無制限になるわけではない。所有者が後日プランを変更する場合はこの前提を再確認する。

公式資料：[Cost control](https://supabase.com/docs/guides/platform/cost-control)、[Pricing](https://supabase.com/pricing)、[Realtime limits](https://supabase.com/docs/guides/realtime/limits)。2026-10-22確認。

## 公開する権限とデータ

ユーザーが承認した `supabase/002_anibato_free_rooms.sql` と接続関数だけを追加。非公開スキーマの2表と専用3関数を使用し、既存の共通10テーブル・コイン・Auth設定を変更しない。`001_common.sql` は適用しない。

部屋ごとの128bit参加キーが必要。DBへはキーのSHA-256だけを保存し、招待コードやSDPをログ・Gitへ保存しない。専用RPCはservice_roleにだけ実行権限を与え、公開Edge Functionが許可済み3操作に限定して呼ぶ。サーバー鍵はSupabaseの既存環境変数でのみ読む。ブラウザの設定ファイルには公開窓口URLとFree指定だけを置く。

公開窓口は新規 `anibato-free-rooms` のみJWT検証をオフにし、短命の部屋権限・サイズ・回数・用途制限を検証する。共通サービスの認証やRLSは変更しない。クライアント申告によるコイン発行・ランキング報酬は実装しない。

## 接続上の限界

無料STUNだけを使うため、企業・学校等のファイアウォールや一部のNATでは直接接続できない。接続可能な回線でも遅延分の入力待ちはある。現段階は招待対戦の試験版で、競技向けのロールバック・観戦・再接続・ランク戦は対象外。

同一PCの2ブラウザ画面による実接続と、離れた2回線による実機テストを区別する。今回の実施結果・件数・公開状態は `RESUME.md` と `codex_logs/free_online_verification.json` に記録する。

## 配布と引継ぎ

Unityの圧縮データ1ファイルがGitHubの100MB制限を超えるため、`tools/verify/pack_portal_webgl.cjs` が8MiBずつに分割する。ゲームの範囲だけで動くService Workerが各片のSHA-256を確認し、Unityへ元のバイト列として返す。原画・戦闘値を削減しない。

Webの正本HTMLは `tools/webgl/index.html`。WebGLBuilderがAssetsのテンプレートへコピーする。JS/CSS/接続設定/workerは `AniBato/Assets/WebGLTemplates/AniBato/`。HTMLだけAssets側を直しても次のビルドで戻るので注意。

公開用ポータルは最新 `aniani-asobiba` のGitチェックアウトへ反映する。古いデスクトップのコピーを公開版へ上書きしない。ガチャはローカル保存の無料試験版で、紙待機9枚SSRとサポート8組SRを末尾追加、全176枚。元159枚・保存キー・レア率を維持し、対戦の強さと連動させない。
