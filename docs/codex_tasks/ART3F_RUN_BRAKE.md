# ART3F：走りの急停止・左右切り返し

2026-10-13 ユーザー追加依頼。ART3Eの歩き/走り/通常を完成させてから順に制作・実装する。Codex/Claude交代可。

- 透真/蓮/千鶴の急停止（足を前へ突いて上体を後ろへ、膝で受けて落ち着く）を新しいピクセルアートで生成。左右の切り返しにも表示する。
- ユーザーのロボット参考画像は動作理解のみ。キャラクター/画風/第三者画像を素材やキットへ収録しない。
- 採用済み立ち倍率・頭/髪/フード・靴を保持、224×160 RGBA/PPU50/pivot(0.5,0)/接地159/共通32色/binary alpha、頭部±2px。全姿勢に同じ立ち由来倍率。透真の端末の持ち手を維持、千鶴は攻撃以外カバンなし。
- 立ち物差し＋制動/沈み/落ち着きの3姿勢を1人ずつ生成・検査し、短い非ループの描画クリップへ接続。原画/実全文プロンプト/採否/倍率/画素検査/GIFを保存し、詳細指示書とキットを更新する。
- シミュレーションの入力・速度・ダッシュ期間・攻撃・当たり判定は維持。描画側で直前の走り→停止/逆方向の遷移を検知し、特に反転時に制動姿勢を短く表示して新方向の走りへ戻す。歩きだけの停止には表示しない。被弾/攻撃/ジャンプ等は優先、リスタート/無効化/再開で古い制動を持ち越さない。
- 実装前に入力/描画の現状を読み、具体的なフレーム数・反転時の向きと割り込み仕様を本書へ追記する。両方向/停止/反転/割り込み/リセットを実UnityのSpriteRendererで検査。
