# 空中・下攻撃は1原画、通常は2原画（2026-10-17最新指定）

最新のユーザー指定を優先する。全9人の空中ニュートラルと地上下攻撃は各1原画を採用し、発生から硬直まで同じ決め絵を表示する。千鶴の添付は現在の空中当てる原画なのでそれを選定する。通常1・2段は共通の予備／当てる2枚、通常3段は大振りの予備／当てる2枚を維持する。

既存の2枚組は当てる側を選び、未生成キャラの空中・下は決め絵1枚だけ制作する。予備を追加生成しない。他の動作も追加差分が必要になった際のユーザー指示で増やす。予定済みの未制作技の原画は人物順に継続するが、既存で動作が伝わる姿勢へ自動的に原画を増やさない。溜め・被弾の追加制作も不足を報告し、追加指定後に進める。

採用枚数は表示の設定であり、発生／有効／硬直、判定、ダメージ、前進、重力は変更しない。空中停止と空中方向別攻撃を復活させない。元の生成候補は保管して再生成を防ぎ、ゲームで使用する1枚と候補2枚の区別を確認フォルダへ明記する。保護カバンは保持。

Editor生成で全員の該当姿勢を分離し、同じ姿勢を他状態が共有していてもそちらへ変更が漏れないようにする。選んだ原画の頭・足・原点計測も同じインデックスから選ぶ。BuildAllの再実行でも1枚採用を維持する。今後の取込は1枚の空中／下を受け入れ、不完全な通常2枚組は拒否する。

実入力で発生・有効・硬直・解除と左右の見た目、空中重力を検査する。通常の予備→当てる、特殊のおにぎり発射同期、超必殺の持続は保持する。千鶴3段の手と集合絵の修正も未コミット差分を捨てずに継続。実Unity4工程後に資料・確認フォルダ更新、通常保存・pushする。
