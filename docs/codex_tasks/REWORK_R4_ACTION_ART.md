# R4：固有技・上／下攻撃の原画

R3の技とキータイミングを確定後、1人の原画を完成・比較・接続してから次へ。制作順は透真→蓮→千鶴の不足→湊→シロ→結衣→黒獅子王→暁→龍太。既存の全9人待機と基本45ポーズは再生成しない。溜め専用の原画は今回生成しない。

各人の採用待機を必ず見て参照する。通常のアニメ塗り全身、薄い白縁、透明背景、斜め横で両腕両脚のつながりが分かる姿勢。関節分割やボーンなし。頭・髪・靴・手・道具の大きさと服の設定を待機へ固定する。

必須は地上上／下、特殊、超必殺の各「予備→当てる」2枚。武器変更で既存通常を使えない人物は通常3段も各2枚。3段目は最大の予備と当てる。現在の空中攻撃はNのみ、専用絵が不適切な人物は同じ原画方針で追加。大量の中割りやゲーム側のぬるい補間で補わない。

共通ゲーム枠1304×1450、PPU532.5893、靴底1328、立ち基準の人物倍率を維持する透明梱包。姿勢ごとの収まりで人物を独立拡縮しない。原画と梱包は分けて保存し、等倍と整数拡大で頭／靴／手を見比べる。全身サイズだけの合格にしない。採用版・全文プロンプト・SHA・微差／未承認事項をmanifestへ。

千鶴はフライパン／おたま左手、カバン予備は右手。おにぎりの持つ絵と飛ぶ絵の世界幅を合わせる。胸側か背中側かを決め、肩→肘→手首→掌／甲→親指を一続きで確認する。単なる左右反転では解剖学的な間違いの修正にならない。シロは四足、湊の義手と機械眼は左、結衣の右は肉球ミトン・左は素手と杖、黒獅子王は獅子の頭巾の下の人顔を維持。

生成は内蔵image_genとimagegenスキルを使用。生成結果だけを採用済みと呼ばず、本人ごとに梱包とゲーム参照を確認。イラスト確認フォルダには現在採用版を動作名で保存し、旧候補と混同させない。保護対象は削除しない。

R3の発生・有効・硬直や判定を絵に合わせて変更しない。実FighterViewとSprite切替を実Unityで検査し、左右・予備／有効／解除・実描画を保存。全4工程合格で通常保存し、絵の最終承認待ちの微差は残課題に記録。
