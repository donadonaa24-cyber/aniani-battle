# R0：溜め攻撃（専用絵生成なし）

R1〜R6の依頼を保持し、2026-10-16追加の溜め攻撃を先に小工程として実装する。

地上通常押下で溜め姿勢。60tick未満の解放は通常、60〜180tickの解放は溜め通常。180で威力上限、保持で自動連打しない。空中は従来通常。地上方向を押下時に保存し、コンボの追加入力は押下受付を継続。

通常1発の蓄積と時間に比例した吹っ飛び。最大は現在のメイン足場の向き側の端付近へ（場外線ではない）。被弾中断、溜め中無敵なし。数値はBattleRulesに置きEditorで新ルールへ明示移行し、旧フェーズfixtureは旧ルールを保持する。

既存全身絵を少し傾け、沈み込み、色と紙片の溜めエフェクトで表示。コライダーと実位置は動かさない。今回はimage_genを呼ばない。

59／60／120／180／上限超過、短押しと空中、被弾中断、1蓄積、可変吹っ飛び、左右と縮小後の足場端、保持で多重発動しないことを検証。実ゲームの新ルールとRendererの変形・解除を確認。実Unity rework_r0_3でEdit484／Play49と全4工程が合格。通常保存し、R1〜R6を未完として続ける。
