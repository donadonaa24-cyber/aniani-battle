# Windows・Android試作版のポータル配布（2026-10-23）

所有者の最新指示：あにあにポータルからWindows版・Android版もダウンロード可能にする。従来の「配布リンクなし」をこの公開依頼で変更する。

1. 既存検証済み成果物を使用する。Windowsは`Build/mobile_final_2/`の実行ファイルとData・ランタイム・ライセンスを一式ZIP化、Androidは`Build/Android/AniBato-arm64.apk`を使用する。ゲームコード・原画・戦闘値は変更しない。
2. 再現用梱包スクリプト、導入手順、SHA-256一覧を用意し、ZIP全エントリの内容とAPKの既存署名検査記録を照合する。デバッグ出力・秘密情報・個人の絶対パスを配布物へ追加しない。
3. ゲームリポジトリのGitHub Releasesで試作版を公開する。費用の発生するStorage/LFSを使用しない。
4. `TestResults/portal_release/`の最新mainから作業ブランチを作り、紹介ページ・作品一覧・詳細に直接ダウンロードを追加。必要なOS、Windowsの全展開、Androidの試作用署名/実機未確認、招待対戦はブラウザのみを案内する。
5. 既存のリンク許可テストを新仕様の厳密なリリースURL許可へ更新し、全回帰・PC/モバイル表示・公開HTTPのファイルサイズ/ハッシュを確認する。
6. 通常PR/CI/merge/Pages反映を確認し、RESUMEと実装状況へ公開先・証跡を記録する。既存の未コミット生成画像・シーンは保持する。

Unity製品コードを変更しないため、前工程の実BuildAll・Edit834/834・Play111/111・Windows成功とAndroid署名/ABI検査を引き継ぎ、今回は梱包とWeb配布の検証を実施する。
