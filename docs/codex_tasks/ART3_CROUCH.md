# ART3C：新しゃがみ素材・再制作指示書（2026-10-12）

## ユーザー依頼

透真・蓮・千鶴のしゃがみピクセルアートを、ART3Bと同じ条件で崩れないよう生成する。サイズや詳細条件を他の環境でも再制作できる指示書に追加する。

## 固定する条件

- 全員224×160px/コマ、透明PNG、足元y159、胴の基準x112、PPU50、pivot(0.5,0)。身長基準は透真124/蓮100/千鶴112px。原画・既存素材は保持。
- 新待機を容姿/衣装/ピクセル倍率の正しい参照にする。頭・顔・靴を小さくしてしゃがみにしない。膝と腰を曲げる。右向き、全身可視、顔の角度を維持、2本の腕/脚、両足を接地。千鶴のスカートは脚を自然に覆う。
- 生成時は同倍率の立ち/しゃがみの2姿勢を並べ、立ち姿勢を縮尺の物差しに使う。しゃがみの外接高さへの独立リサイズは禁止。キャラ全クリップ共通32色以内、二値alpha、整数ピクセル、Point/Mipなし/圧縮なし。
- 最終しゃがみ8F/6fps、約1.33秒。1枚の採用しゃがみ絵から整数行移動の微小呼吸を作り、顔/衣装画素と靴の下12行を固定。前後絵のブレンド・ゴースト・全身拡縮なし。

## 作業

1. tasklist/git statusと引き継ぎ資料を確認し、別担当の同時編集がないことを確かめる。
2. 内蔵image_genで各人の新待機を参照した2姿勢原画を生成。原画/最終プロンプトをart_source/art3_crouch/へ非破壊で保存。頭・顔・衣装・膝/足の形を目視確認し、不良は採用しない。
3. SpriteForgeで立ち参照由来の共通倍率を使って正規化。crouchのみprebuiltSheetで差し替え、8枚/人・1792×160横シート・JSON・GIFを出力。idleや他モーションのPNG/ID/Timing/性能を保持。
4. SPRITE_SPEC.mdにモデルに依存しない再制作条件、キャラ別容姿/参照/パレット、原画と実装用寸法の違い、しゃがみの倍率維持、コピペ用プロンプト、出力JSON、検査とやり直し基準を追記。自己完結した参照PNG/プロンプト/パレット/規格の生成キットも保存する。
5. 全24Fを検査：共通サイズ/倍率/足固定/二値alpha/色数/実頭頂高さ/顔と胴の画素一致/GIF復号/再生成一致。Unityアセット回帰を必要な範囲で追加し、既存アサーションを維持する。
6. tools/verify/run_unity.ps1 -Tag art3cをサンドボックス外で承認実行。BuildAll/EditMode/PlayMode/Windowsビルド全合格を確認。実キー撮影前は必ず「PCに触らないで」と声をかける。
7. STATUS/RESUME/HANDOFF/ASSET_SOURCES/最終報告を更新。全合格後にcommit・origin mainへ通常push。Claudeへいつでも交代できるよう原画・プロンプト・再現手順・検証結果・残課題を残す。

## 範囲

新しゃがみと再制作資料が対象。新待機は維持する。移動/攻撃/勝敗などの描き直しは次の作業。新しいモーションも同じセルと倍率を使う。
