## まず直すこと
1. **PlayModeテストの入力基盤**：`Unity.InputSystem.TestFramework` の `InputTestFixture` を使う方式に作り直す（テストasmdefに `Unity.InputSystem.TestFramework` 参照、`InputTestFixture` を継承または合成し、`InputSystem.AddDevice<Keyboard>()`＋`Press/Release`、もしくは `InputSystem.Update()` を明示呼び出し）。バッチモード（グラフィックあり・フォーカス無し）でも通ること。必要なら `InputSystem.settings.backgroundBehavior = IgnoreFocus` と `editorInputBehaviorInPlayMode = AllDeviceInputAlwaysGoesToGameView` をテストのSetUpで設定し、TearDownで戻す。**アサーションを弱めて通すのは禁止**。
2. ゲージ獲得量の確認：現状、通常攻撃3ヒットで攻撃側36・被弾側24まで増える。70秒で超必殺1回が「狙えば撃てる」程度か、逆に早すぎないか、フェーズ5のCPU同士テストで最終調整する前提で、現時点の想定（何秒・何ヒットで100に届くか）を `BALANCE_CONFIG.md` に書く。

## 実装（docs/SPEC_ORIGINAL.md 2章・3-4・4-2・9章）
各キャラを `CharacterData`（ScriptableObject）＋各 `AttackData` で定義し、**戦闘システム本体を書き換えずに**キャラを追加できる形にする（必要な汎用機能はシステム側に「データで指定できる効果」として追加）。

### 共通
- 移動性能・通常攻撃（地上3段／空中）・特殊4種・超必殺・カウンター固有効果をキャラごとに差別化（発生、射程、移動量、硬直、吹っ飛ばし、追加効果）。
- **カウンター固有効果**：`ICounterEffect` をキャラ単位（P1/P2それぞれ）で差し込めるようにする（現在はシミュレーション全体で1つ）。
- **超必殺技**：ゲージ100消費、命中でハート2、通常ガード不可・通常回避不可、ジャストガード／ジャスト回避で防御可、範囲外なら当たらない、空振りで大硬直、1試合1回。発動時 `UltimateStarted` イベントで**キャラ固有カットイン**（名前・技名・キャラ色の帯。画像があれば立ち絵）。カットイン中の時間停止は短く（暗転 0.5秒程度、データ化）、停止中もタイマーの扱いを明確に。
- 汎用の追加効果（データで付与）：麻痺（短時間行動不能。最大でも 45F 程度、データ化）、自己回復（自分の通常被弾蓄積 -1）、一時強化バフ（移動速度／攻撃発生などの倍率と持続F）、吹っ飛ばし倍率、アーマー無し。

### 透真（テクニカル：解析・防御・カウンター・機動力）
- 通常必殺「観測パルス」：中速の飛び道具（短い射程、命中で相手を短時間スロー or 解析マーク表示など。地味でよい）
- 横必殺「遮断ステップ」：短距離高速ステップ＋終わり際に判定（すり抜け／短い無敵は控えめに）
- 上必殺「緊急上昇」：縦方向の復帰技（移動量大、攻撃判定小）
- 下必殺「防御・妨害技」：その場にシールド／妨害フィールド（飛び道具を消す、短時間）
- 超必殺「境界突破」：前方への高速突進。演出はSF装備によるクロスオーバー表現（**原作の超能力として扱わない**）
- カウンター固有効果：成功後 N 秒、移動速度・ダッシュ性能を一時強化

### 蓮（高速・直線突進・攻撃特化。将棋の飛車＝縦横に直線移動）
- 通常必殺「飛車ライン」：前方への長い直線判定（発生やや遅め・射程長い）
- 横必殺「直線番長」：横方向の高速突進（移動量大、ガードされると隙大）
- 上必殺「縦抜け」：真上への直線移動（復帰・対空）
- 下必殺「構え・急襲系」：構え → 入力で前方急襲（構え中はカウンター判定ではない。カウンターと区別すること）
- 超必殺「十字突破」：縦横十字の判定（飛車の動きのイメージ）
- カウンター固有効果：成功時の吹っ飛ばし距離増加

### 千鶴（料理・中距離・変則・自己回復）
- 通常必殺「爆弾おにぎり」：放物線の投擲。命中した相手がおにぎりを食べて短時間麻痺（演出「もぐもぐ」、麻痺は長すぎない）
- 横必殺「フライパン突撃」：フライパンを構えた突進（正面の飛び道具を1回弾く程度は可）
- 上必殺「おたま旋風」：回転上昇（復帰技、多段ヒットにしない＝1ヒット）
- 下必殺「食事による自己回復」：食事モーション（隙あり）→ 自分の通常被弾蓄積 -1（ハートは回復しない）。連続使用を防ぐクールダウン
- 超必殺「満腹カレー！」：広めの範囲攻撃（カレー鍋の演出）
- カウンター固有効果：成功すると自分の通常被弾蓄積 -1（データで調整可能）

## 選択と起動
- キャラ選択画面はフェーズ4なので、このフェーズでは **Battleシーン上で P1/P2 のキャラを切り替える仮手段**（例：試合終了画面で F1/F2 でP1キャラ、F3/F4 でP2キャラを切替 → R で再戦。または `BattleSetup` ScriptableObject）を用意し、README に記載。初期は P1=透真、P2=蓮。

## テスト
- 3キャラそれぞれ：4種の必殺技が発動しヒットでハート-1、超必殺命中でハート-2、カウンター固有効果が発動。
- 爆弾おにぎりの麻痺時間が上限を超えない、自己回復で蓄積-1（0未満にならない）、ハートは回復しない。
- 蓮のカウンター効果で吹っ飛ばしが増える、透真のバフが時間で切れる、千鶴のカウンターで自分の蓄積-1。
- 上必殺技で3キャラとも場外近くから復帰できる。
- 超必殺技は1試合1回、空振り硬直、カットイン中のタイマー扱い。
- 仕様12章19「3キャラとも操作可能」に相当するPlayModeテスト（各キャラで移動・通常・特殊が出る）。
