# 千鶴の大胆な一枚絵走り（2026-10-14）

ユーザー指定：「次は走りのイラスト」「さっきの画像サイズとずれが起きないように」「走りのポーズはこれくらい大胆」「これも紙芝居のように揺らして動かす」。千鶴だけを継続し、待機/歩行は合格済みの60501c4（origin main）を保持する。

## 生成・大きさ

- 内蔵image_genで紙人形の走り原画1枚を生成。本人の採用済み紙待機原画を容姿/画風/頭と靴/衣装/色/倍率の主参照にする。ユーザー添付の走る人物は大胆な腕脚/前傾の意味だけ参考にし、その絵柄/人物/文字/背景を写さず公開素材へ保存しない。
- 茶色ボブ/茶色の目/オレンジセーター/紺フレアスカート/白スニーカー、両手両脚が見える斜め右向き、強い前傾と大きい踏み出し、後脚を曲げ、前腕を上げ後腕を引いた躍動的な走り。一枚の全身、太い茶輪郭/細いクリーム紙縁/アニメ塗り/透明背景。カバン/武器/影/速度線/台座は不要。
- 待機1246×1263を共通キャンバス基準とし、頭/髪/顔/靴/胴/手脚の長さを待機と同倍率で比較する。走りの高さが低くなっても全身の縦寸法に合わせて独立拡大しない。前傾による自然な高さ/幅の変化は許容。生成結果の寸法/透明/端切れと実部位の大きさを測定し目視、ずれがあれば再生成で修正する。
- 原画/最終全文日本語プロンプト/主参照とポーズ参照の役割/実寸/SHA/採否/倍率条件をart_source/paper_cutout/へ保存。既存原画は上書きしない。

## Unityの走り

- 千鶴のDash状態だけ走りの紙Spriteを使用。Idle/Moveの紙Spriteと揺れは保持、その他は旧アニメ。透真/蓮は変更しない。
- 走りのインポートPPUは待機の532.5893基準で固定し、足元ピボット/原画全身/左右反転を揃える。走り全身の高さからPPUを再計算しない。前傾でも頭と靴が大きくならないことを確認する。
- SOへ走りSprite/独立の揺れ設定/足幅を追加。一枚の全身を段階的に左右へ傾け、少し上下させて走りを演出。更新は既存の固定tick Age、判定/速度/スタミナは変更しない。歩き↔走り↔待機/攻撃/ポーズ/再戦で表示と揺れを切り替える。走りがない設定やEnabled OFFは厳密に旧表示へ戻る。
- 原画とUnity描画の部位/足元、実Rendererの走り/反転/状態切替/固定tick停止をテスト。旧ピクセルの画素/寸法テストは維持し、千鶴Dashのライブ期待だけ紙Sprite参照へ更新する。
- tools/verify/run_unity.ps1 -Tag paper_chizuru_run_1をサンドボックス外の承認で実行し、BuildAll/EditMode/PlayMode/Windowsビルド全合格を確認。UnityカメラのPNGとそのGIFを保存して目視。OSキーを送る実機撮影の前は必ず「PCに触らないで」。
- STATUS/RESUME/HANDOFFを実件数/画像/残課題/次の手順で更新し、全4工程合格の区切りを通常commit/pushする。停止中の透真制作は再開しない。
