# 残像の比較実装（2026-10-24）

所有者指定：薄い残像で移動・攻撃を滑らかに見せる案を実装し、いつでも元に戻せる状態にする。

- 通常移動には既存の固定tick位置補間がある。入力・移動速度・攻撃発生/硬直・判定・ヒットストップは変更しない。
- ダッシュと通常攻撃の振り抜きだけに、全身Spriteの薄い残像を最大2枚、約0.1秒で消す。原画・テクスチャ・マテリアルを複製せず、小さな固定プールを再利用する。
- 過去の絵をその場所に残し、本体より背面へ表示する。停止時は速やかに消す。ポーズ・ヒットストップ・練習停止は進めず、被弾/瞬間移動/崖つかまり/入場/決着/再戦/キャラ変更時に前の残像を持ち越さない。
- 設定に「残像 ON/OFF」を追加。OFF直後に残像を消し、既存の描画へ完全に戻す。設定は端末へ保存し、通常の設定/ポーズから変更可能。描画だけなのでオンラインの戦闘状態に影響させない。
- 数値はPresentationSettingsから。新しい画像生成・戦闘Data編集・旧原画削除は行わない。
- EditMode/PlayModeでプール上限・減衰・停止/切替・描画だけの変化を検査し、実UnityのBuildAll/EditMode/PlayMode/Windowsを順次実行。比較画像を保存する。既存の未コミット2シーン・生成スクショは保持。
- 元版は公開済みv0.1.1とコミットd0f7485に保持。試作ビルドは別名にする。ポータル/配布版の差し替えは今回行わず、まず比較できる試作を完成させる。
- 終了時にRESUME/IMPLEMENTATION_STATUSへ件数・保存場所・切戻し方法を記録し、検証後に通常commit/push。
