# 残り8人の専用7動作原画（2026-10-18）

## 最新の依頼と範囲

千鶴に専用原画があり他の8人にまだない7種類を生成し、ゲームへ接続する。各動作は全身1枚。走り、ジャンプ上昇、落下、回避、カウンター成功、通常被弾、ハートが減る強被弾。8人×7枚＝56枚。通常攻撃4原画、上攻撃、下と空中N各1枚、既存の基本5姿勢は維持。溜め専用絵は今回の範囲に含めない。

## 実装順

透真 → 蓮 → 湊 → シロ → 結衣 → 黒獅子王 → 暁 → 龍太。人物の原画生成は1人分の7枚を揃えてから次へ進む。前人物のUnity検証中は次人物の原画保存のみ進めてよいが、次人物のpacked-manifestとUnity接続は前人物の検証終了後とする。検証中のアセット集合とC#を変更しない。同時編集・並列人物生成をしない。

## 原画と表示

- 採用待機を容姿・部位実寸・頭身の基準とする。必要な既存姿勢はポーズ参考として明示する。
- 内蔵画像生成を1原画ごとに使用。原画、全文条件、参照の役割、版、SHAを `art_source/paper_roster_motion/` に保存。
- 左右の肩から手首までの接続と親指、5指、衣装、装備の持ち手を確認。シロは四肢4本。肉球ミトンを人間の手にしない。
- 通常被弾は上体が後ろに傾きつつ耐える。強被弾は痛みが伝わる表情と大きいのけぞり。血や傷は追加しない。
- 1304×1450、PPU532.5893、靴底1328、支点(652,122)。透明梱包と整数移動のみ。枠へ拡縮せず、待機と頭髪・靴等を比較し記録する。
- 全身1枚を回転・移動する既存のリミテッド表現を維持。関節分割やボーンを導入しない。

## 接続

BuildAllで完成人物の7枚を再接続する専用Builderを追加。Dash、Jump、Fall、Dodge、CounterSuccess、Hitstun/Knockback、HeavyDamageへ対応。CounterSuccessを構えと分け、Counter自体は既存絵を残す。HeavyDamageは既存のLastDamageLostHeartに従う。戦闘値・判定・ゲージ・物理・入力タイミングは変更しない。千鶴および保護カバン版は維持。

シロの走りだけ、四足の水平な胴を45度倒して鼻先が床へ向くのを避け、全身スプライトのDash傾きを10度にする。人間のDash45度と全員の歩行15度は維持。速度や衝突判定には影響しない。両方向の角度・安定性を固定値で検証する。

人物ごとに7枚の接続、左右、被弾の通常/強の分岐、解除、全身描画と支点、反復描画で戦闘が変わらないことを確認。既存の待機代用テストは専用絵を接続した人物のみ専用絵を期待するよう変更し、未完成人物の代用検査を残す。アサーションを弱めない。
