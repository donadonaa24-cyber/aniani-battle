# R1：攻撃入力の整理と練習無制限

SPEC_REVISION_20261016に従う。全9人の地上上／下は既存の方向選択を確認し、不足を追加。空中は方向にかかわらずAirNeutral。空中攻撃の滞空処理は除去し、通常の重力・速度で進む。命中による共通ヒットストップを維持。

特殊入力は向きの変更と攻撃種の選択を分け、全方向からNeutralSpecialへ統一する。千鶴の同技は既存おにぎりを使用。旧方向特殊定義は予備で保持し、選択経路から外す。

通常同士の同tickの有効判定重複は双方Clash。開始tickが違っても、そのtickで実際に双方の有効判定が重なっていれば同時衝突として扱い、発生前／硬直中を含めない。攻撃インスタンスIDと接触処理の順序を確認し、片方だけ先にダメージを通さない。特殊・超必殺との従来優先度は維持。

練習は開始時満ゲージ、超必殺使用後も次回が使える満ゲージを維持。対戦開始や練習終了時に通常ルールへ戻し、回数カウンターや一度限り制限を残さない。入力クールダウン／超必殺硬直は通常どおりで、連続押下で同tick多重発動させない。

テスト：4方向の空中入力すべて同じ技、空中通常中の水平と垂直推移が通常移動と一致（命中なし）、地上上／下の独立選択、特殊の方向共通、通常同士Clash・非同時・優先度、練習開始直後と2回以上の超必殺・通常対戦への復帰。
