# 溜め攻撃の専用原画と龍太の左拳修正（2026-10-19）

## 今回の依頼

9人全員の溜め中専用全身原画を各1枚生成・実装する。既存の通常、上下、空中、特殊、超必殺、専用7動作は維持。溜め解除後は入力方向に合う既存の攻撃原画へつなぐ。溜めの1～3秒、1通常被弾分、段階的な吹っ飛び、最大時の端への移動、判定・入力・ヒットストップは変えない。

追加指示：龍太の走りとジャンプ上昇は、画面右側にある本人左拳が右手として描かれている。拳のまま手の内側と握った指が見える左手へ修正し、身体・もう一方の手・衣装・靴・ポーズを保つ。ユーザー承認の通常被弾v5は変更しない。前回の甲側へ統一する指示解釈を優先しない。

## 作業順

1. 龍太の走り・上昇を内蔵image_genで直接編集。承認済み通常被弾v5の握り拳を形の参考にし、ポーズ全体はコピーしない。候補・全文条件・参照役割・SHAを履歴へ保存。
2. 溜め原画は透真→蓮→千鶴→湊→シロ→結衣→黒獅子王→暁→龍太の順。採用待機の容姿・頭髪・靴実寸と、採用攻撃の持ち手を参照。人間の左右の肩・肘・手首・5指、ミトン、シロの四肢を確認。各1枚、透明、白縁、低い強い溜めのシルエット。文字・効果は焼き込まない。
3. 原画を1304×1450・靴底1328・PPU532.5893へ整数移動と透明余白で梱包。姿勢ごとの独立拡縮をしない。溜め専用はart_source/paper_charge/へ記録。日本語確認フォルダと採用一覧を分ける。
4. 描画専用の溜め原画選択を接続。状態名や既存の通常原画の割当を置換せず、Charging時だけ使用する。傾き・沈み・色・紙片の既存演出を維持し、解除・被弾・場外・終了時に残留しない。Webのビルドコピーも専用原画をGPU圧縮側へ写す。
5. 実入力で全9人・左右・1～3秒・最大維持・短押し・解放・中断・地上/空中と、原画選択・重力・支点・戦闘非干渉を検証。既存の待機代用の期待値は専用絵の期待値に更新し、アサーションは弱めない。
6. run_unity.ps1のBuildAll・EditMode・PlayMode・Windows全4合格と、WebGLの新規起動・溜め保持/解放・音声・エラーを確認。Webメモリ512/4096の修正を維持。採用画像を日本語名で保存、RESUME・STATUS・実装順・ASSET_SOURCESを更新し通常commit/push。

千鶴のカバン予備、全員の通常4原画、下/空中N各1原画、半減済み45判定とゲージ14/10を維持する。新規の攻撃瞬間差分や方向別溜め差分はこの工程では自動追加しない。
