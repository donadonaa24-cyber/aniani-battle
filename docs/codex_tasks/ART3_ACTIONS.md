# ART3D：ジャンプ・ガード・回避・ダッシュ（2026-10-13）

## ユーザー依頼

採用済みの待機/しゃがみと同じ3人で、ジャンプ・ガード・回避・ダッシュを生成する。順番に生成して確認してよい。追加姿勢だけ人物が大きくならないよう、頭/髪・靴も待機基準で合わせる。

## 固定条件と範囲

- 全3人224×160px/コマ、PPU50、pivot(0.5,0)、Point/Mipなし/圧縮なし、透明RGBA、二値alpha、既存キャラ共通32色。立ち基準は透真124/蓮100/千鶴112px。
- 採用済みART3待機の容姿/顔/衣装/倍率を参照。千鶴は私服。原画・旧raw・既存待機/しゃがみを保持。第三者素材/装備/衣装を追加しない。
- 同一原画内の立ち姿を倍率の物差しにする。各動作/コマを外接高さへ独立リサイズしない。頭/髪・靴の寸法を採用待機と等倍/整数拡大で確認。別角度の投影幅の変化は目視も記録。
- 順番はジャンプ→ガード→回避→ダッシュ。各人の立ち＋その動作のキーを内蔵image_genで1枚ずつ生成し、容姿/関節/部分倍率を確認して次へ進む。接触・二重腕/脚・顔崩れ・服省略・画像端切れは採用しない。
- ジャンプの上昇/頂点/下降と着地を新しい絵柄に揃える。地上の接地はy159、空中は既存centerアンカーを保つ。ジャンプ/fall/land/guard/dodge/dashの既存フレーム数・fps・loop・Binding/Timing/スプライトIDを維持。
- 回避は構え→低い横回避→復帰の読みやすい3キー、ダッシュは足を交互に動かす4キー。地上/空中ダッシュは既存Dash状態の同じクリップを使用。複数キーの画素を混合しない。
- 戦闘tick・速度・ジャンプ高・当たり判定・無敵/ジャスト/ガード性能・入力は変更しない。

## 追加指定：ジャンプ予備動作と反動（2026-10-13）

ユーザーはジャンプ前と着地後に少しかがむ絵を要求し、追加質問で「2フレームかがんでから踏み切る」を選択した。**地上ジャンプに実際の2tick（約0.03秒）の予備動作を入れる**ことは上の性能維持の例外として許可済み。空中2段ジャンプの踏切は維持。浅いかがみを新規生成し、地上予備動作と着地反動に使用する。既存landの2F/15fps・8tick表示枠を保ち、最初を浅いかがみ・次を待機へ戻る絵にする。

戦闘側は純C#・データ化した2tickの地上予備状態を追加し、接地中2tick→同じ初速で踏切、二重消費なし、被弾/場外/足場消失時の扱いをテストする。入力テストの旧ジャンプ判定は予備動作後の実踏切まで待って同じアサーションを検査し、即時に踏み切ったと偽らない。描画は予備状態をlandの浅いかがみへ接続し、既存106クリップ584Fの構成/IDを保持する。新状態のenum値は末尾へ追加し、既存値を変更しない。

## 手順

1. tasklist、AGENTS→HANDOFF→RESUME→STATUS、原本仕様、再制作指示書とGitを確認。同フォルダの別active担当なし・作業ツリーcleanを確認して開始。
2. 動作12枚＋浅いかがみ3枚の原画を順番に生成し、art_source/art3_actions/generated/へ保存。再生成時は旧原画も残しsource-selection.jsonへ採用版を記録。参照の役割/実際の全文プロンプト/原画寸法/採否を記録。静止基準との比較を保存。
3. SpriteForgeの専用加工で立ち由来の共通倍率・整数配置を適用。検査を通った6クリップ/人だけprebuiltSheetに接続。既存rawの共通縮尺/パレットを保持し、対象外PNGを変更しない。
4. 実装用個別PNG・シート・JSON・等倍GIF/3倍プレビュー・接続/部分倍率の記録を作成。詳細指示書と持ち出しキットに新動作の作り方/アンカー/キー割当/参照を追加する。
5. 全コマのセル/部分倍率/二値alpha/共有色/余白/頭頂実測/GIF復号/キー非混合/再生成SHA-256一致、既存待機としゃがみ回帰を検査。Unityアセットテストで新6クリップの状態→全コマ・fps/loop/接地・ID/Timing保持を確認。既存アサーションは弱めない。
6. tools/verify/run_unity.ps1 -Tag art3dをサンドボックス外で承認実行し、BuildAll/EditMode/PlayMode/Windowsビルド全合格を確認。実キー撮影前に必ず「PCに触らないで」と案内し、最前面チェックを維持。
7. 各区切りにSTATUS/RESUMEを更新、最終結果/未確認点/Claude交代手順を残す。Unity全合格後にcommit・origin mainへ通常push。
