# 千鶴の紙人形待機・一枚絵歩行をUnityで試す（2026-10-14）

ユーザー指定：「千鶴だけユニティでも歩きと待機を生成されたイラストに変更して動きを確かめてみて」。PAPER_CUTOUT_PROTOTYPEの待機1枚を実装し、実Unityで確認する。透真/蓮の画風変更・停止中の透真新技は再開しない。旧素材/未コミット差分を保持し、破棄/リセットしない。

## 実装前の具体仕様

- 元画像art_source/paper_cutout/generated/chizuru_paper_idle_v1.png（1246×1263 RGBA）を同じバイトのままUnityの別フォルダArt/Paperへコピー。新しい原画は不要。既存SpriteForgeの224×160/32色クリップはそのまま保管/検査する。
- 千鶴だけ新しいScriptableObjectの紙人形設定を持つ。Idle/Moveのときだけ新しい一枚を使用し、Dash/Jump/Attack/Guard/被弾/勝敗は既存アニメへ戻す。画風の混在は試作の既知の制限と記録。
- 元PNGのalpha32以上の全身外形を測り、立ち高さを旧千鶴の112/50=2.24 world unitsへ合わせるPPUを設定。ピボットは画像中央X/足の最下端Y。Bilinear/Uncompressed/NPOTNone/mipmapなし、sRGB/透明対応。セル固定の旧ピクセル要件を新しい高解像度立ちへ適用しない。
- 設定値はSOで保持：待機の傾き±0.75度/4fps、歩行±5度/8fps、歩行の上下幅0.025u。8段階の振り子（-1,-0.4,0,0.4,1,0.4,0,-0.4）と上下（0,0.5,1,0.5,0,0.5,1,0.5）を一秒で反復する。
- SpriteRendererの子だけ足元を支点にZ回転。足の左右幅から必要な持ち上げを加え、傾けた足が床へ沈まないようにする。顔/服/頭/靴を拡縮/変形しない。向きは元のFlipX、反転でも足元補正を正しく計算する。
- 更新はFighterAnimationPlayerの固定tick Ageを使い、描画FPSで速度を変えない。ポーズ/ヒット停止でAgeが止まれば傾きも止まる。移動/攻撃など状態が変われば新状態のAgeから始まる。別モーション/再戦/キャラ変更では子の回転/上下を残さない。
- シミュレーションの位置/入力/速度/当たり判定/スタミナは変更しない。頭上表示は新画像の身長と回転/上下へ追従する。

## 検証

- EditMode：8段階/周期/フレーム保持/両向きの足元/ゼロ角/不正設定、原画とUnity用PNGのSHA一致・インポートPPU/ピボット/高さ・千鶴だけ有効を確認。
- PlayMode：実SpriteRendererで待機/左右歩行/一枚の維持/全8段階/フレーム間保持/ポーズ/攻撃割り込み/再戦/他キャラと両スロットを確認。以前の千鶴ピクセル表示を期待する描画テストは、仕様変更に対応する厳密な紙Spriteの参照確認へ更新し、旧クリップの画素/寸法アサーションは維持する。
- Unityの実カメラでPNGを保存して目視する。必要ならキャプチャしたフレームの動画を作り、原画を動かした外部プレビューと区別する。実機撮影play_and_captureを実行する前は必ず「PCに触らないで」。最前面が取れなければキーを送信しない。
- tools/verify/run_unity.ps1 -Tag paper_chizuru_1をサンドボックス外の承認で実行。BuildAll/EditMode/PlayMode/Windowsビルド全合格を確認。保存済み424/424・32/32を今回の合格と扱わない。新データ/シーン/メタはEditorで生成し手書きYAMLはしない。
- STATUS/RESUME/HANDOFFへ実件数/スクショ/残課題/次の手順を記録。全4工程合格後に今回の区切りを通常commit/push、force push/履歴変更は禁止。停止中の透真差分は記録して保全する。
