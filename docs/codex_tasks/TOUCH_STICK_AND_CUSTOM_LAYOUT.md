# スティック・丸ボタン・操作/HUD配置編集（2026-10-24）

所有者指定：Android等の十字キーをスティック式バーチャルパッドへ変更。アクションは丸ボタン。ユーザーがボタンとキャラステータスの大きさ/位置/透過濃度を変更・保存できるようにする。ステータスの既定サイズは現状の約2倍。Windows・Android・Web共通。

1. 先行の残像試作を実Unity全4で検証し、小工程として通常保存。残像ON/OFFと公開済み元版を保持する。
2. 親指をドラッグして360度に動く円形スティック。距離を制限しデッドゾーンを設ける。指を離す/画面切替/フォーカス解除/編集開始で入力を解除。方向+攻撃等の複数指、溜め解放、メニュー上下左右、既存のキー/物理パッド設定を維持。
3. 表示/配置を編集する画面を用意し、各要素をドラッグして位置変更、選択した要素のサイズ/不透明度を調節。変更は端末に保存。初期配置へ戻す・キャンセルも用意し、画面外へ置けないように制限。編集のドラッグで攻撃/移動しない。
4. 操作ボタンは円形の実描画/押下範囲とし、スティック/各ボタンを個別調整。キャラステータスP1/P2もサイズ/位置/不透明度を調節。既定は旧CompactScaleの約2倍、狭い画面とセーフエリアへ収める。
5. EditModeで保存形式・範囲制限、PlayModeでスティック方向/長押し解除/複数指・編集/保存/キャンセル/リセット・HUD/戦闘不変を確認。実Unity全4→WebGL実ブラウザ→Androidビルド/署名/ABI→Windows復帰。Unityは逐次実行し、実行中にAssetsを編集しない。
6. 所有者から旧APKのAndroid起動成功が報告された。これはユーザー確認済みと明記し、新APKの実機操作/発熱/メモリまで確認済みと拡張しない。
7. 所有者は必要なホームページ/ポータル反映も許可した。全検証後、無料の既存Release/ポータルへ反映し、Windows/Web/Androidを揃える。旧版は上書きせず残す。同一素材/ガチャ所持/無料通信設定/戦闘Dataを保持。
8. 実数・検証証跡・配布版・元に戻す手順をRESUME/IMPLEMENTATION_STATUSと関連資料へ記録する。

## 追加：瞬間移動のカメラ（所有者の同日指定）

瞬間移動後に急拡大して目がチカつく挙動を直す。瞬間移動の発動受付時点で行き先に関係なくフィールド全体の画角へ先行して滑らかに引く。発動後に初めて拡大しない。少し広角を保持し、その後ゆっくり戻る。シロ/湊等の瞬間移動と溜め/分解/再集合を確認し、戦闘/移動距離/判定は変更しない。通常時のカメラ収まり検査を維持し、カメラの時間変化/発動前の拡大/連続発動を追加検査する。
