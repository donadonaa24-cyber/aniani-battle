# 特殊上・全9人の復帰（全体指示書の工程C）

親指示書：DIRECTIONAL_SPECIALS_AND_RECOVERY.md。特殊下の全4工程合格を保存してから実装する。下の独立CDと設置2枚制限を維持。2026-10-20の継続工程。

- 純C#の復帰定義をAttackDefinitionへ追加。上入力の発動方向を保存し、王の2回目はその時点の入力で方向を再決定する。入力なしは前方向／上へ安全にフォールバック。
- 蓮は垂直上昇、結衣は斜め上、王は2回の方向突進。湊・シロは方向転移。透真・暁は方向操作付き浮遊、千鶴は風船で上昇、龍太は本を蹴って上昇。
- 全て接触で通常蓄積+1。1回の復帰中の多重ヒットを防ぐ。再使用は着地とCDの両方が必要。移動は通常の足場AABBへ通し、場外境界を内側へ引き戻さない。転移の行き先は固体へ埋めず、すり抜け足場は通過可能。
- 通常空中Nの流れる挙動を変えない。復帰のための一時浮遊／2段目の間は復帰定義だけに適用。
- N・下・上それぞれのCD、上の着地待ち、王の方向転換を技表・練習・CPUへ接続する。
- 既存の本人の飛／角／王の変身原画、意識状態の回避／ジャンプ原画を使う。新生成の透真ドローン、千鶴風船、暁羽ばたき、龍太本キックを各1原画で接続。原画RGBAを保ち、待機絵の頭／靴寸法と照合する。新しい部位分割や大量中割りは作らない。
- 画像はart_source/directional_specials/、全文条件は同prompts/。生成直後は未接続。採用SHA・寸法・部位比較・日本語の採用コピーを記録する。
- EditMode：全9人左右・入力8方向・王再方向・固体衝突・すり抜け足場・場外・1/3一回・空中再発不可・着地復活・ヒットストップ・割込・CPU・定義移行の保持を確認。
- PlayMode：実キーで全員左右、原画／色／方向とHUD、キャラ間の部位サイズを撮影して確認。全4工程合格後に保存。最終Webと全要求監査は親指示書の工程Eまで残す。

数値はEditorで新しい独立SOへ一度だけ移行し、以降のBuildAllで調整を上書きしない。旧通常45判定、14/10ゲージ、承認済み龍太被弾v5、フライパン原画と保護カバンを維持する。
