# 特殊下・上復帰と固有技の追加（2026-10-19）

ゴールの全範囲を以下のまま保持する。基準HEAD20563ea、作業ツリーはクリーン。前工程BGM/SEの完成はこのゴールの完成と分ける。同フォルダの別CLI担当／Unityエディタなし（Claudeデスクトップの補助プロセスと別作品のUnity MCPは対象外）。

## 確定した要求

1. 特殊入力：ニュートラル／下／上復帰を使い分ける。横だけは現在のニュートラル特殊を維持。全員の各特殊のクールタイムと上復帰の着地待ちを画面へ表示。
2. 湊下：地雷設置、踏むと通常被弾蓄積+1（1/3）。
3. 透真：3段目の弾表示を銃口へ下げる。ロケット拡大。ドローンを遅い対戦相手追跡型、3秒で消滅／爆発へ。下は青白い意識状態で相手の後ろへ瞬間移動。
4. シロ下：同じく青白い意識状態で相手の後ろへ瞬間移動。
5. 蓮／結衣／黒獅子王下：それぞれ飛／角／王へ変身し、超ガードと近い相手を押し飛ばす1/3攻撃。
6. 黒獅子王N：既存のレイラ／シオン／ノアが3方向からターゲットへ突撃。HPダメージなし・麻痺120tick。超必殺は王文字を出さず、3人が左→右→左から順番に水平突撃。
7. 龍太超必殺：呪文が完了してから20秒、移動／ダッシュ1.5倍。**ユーザー追加回答：特殊下も読書し、完了後5秒間1.5倍**。他の候補カウンターは採用しない。
8. 暁：ピラミッドを拡大、落下後は固体の壁。**ユーザー追加回答：着地後10秒で消滅。超必殺の再発動はないため置換を前提にしない**。通常1/2段のカード斬り表示修正。下は罠カード、接触1/3・未命中は20秒残存。**追加指定：相手にだけダメージ、命中したカードは消滅、同時設置2枚まで。設置枚数も表示する**。
9. 千鶴超必殺：既存のカレー直撃後、さらに5秒の設置カレー。繰り返し1/3ダメージ、本人は1/3回復。下は食事、2.5秒動けず1/3回復、CD20秒。回復は既存仕様の通常被弾蓄積を1減らし0で止める。
10. 全9人のスタミナを役割に合わせて調整、SOで保持、根拠を記録。
11. 上復帰：全員、接触1/3。蓮は飛で大きく真上、結衣は角で入力方向の大きな斜め上、王は王駒で入力方向へ2回（2回目は再方向入力可）。湊／シロは意識状態の方向瞬間移動。透真はドローンにつかまって方向へ浮遊。龍太は本を蹴り上昇。暁は腕を羽ばたき方向へ浮遊。千鶴は風船で上昇。

## 実装順と証跡

- A：ダメージの分類と完了時自己効果・新しい入力ポリシー・CD表示の共通基盤。通常3ヒット=1ハート、既存N特殊1・超必殺2、同一攻撃多重防止を既定として保持。
- B：特殊下9人。設置は独立の期限／接触履歴と床追従、超ガードは専用持続とスタミナを使う。瞬間移動はターゲットの向きから後ろを求め、地形内へ入れない。
- C：上復帰9人とCPU・練習・技表・ポーズ/道具表示。着地まで1回、CDと消費は見える形で、場外境界を勝手に内側へ戻さない。
- D：透真・王・暁・龍太・千鶴の残りの固有技。ホーミング、3方向／3段時差、着地残留・壁、繰り返し設置ダメージを共通定義で実装。描画の変更と当たり判定の変更を明記する。
- E：実ゲームの入力／移動／ダメージ／CD／描画を各キャラ左右で確認。BuildAll→EditMode→PlayMode→Windows全合格の小区切りを保存し、最終WebGLと実ブラウザ、全要求対照の監査を行う。各小工程の完了をゴール全体の完了と扱わない。

検証は `tools/verify/run_unity.ps1 -Tag <タグ> -CaptureRoot TestResults/<タグ>/captures` をサンドボックス外で実行。SO生成はEditorコード、一度だけ移行して以後の調整を保持。半減45判定・ゲージ14/10・元の通常原画4枚、下/空中N各1枚、原画RGBA、承認済み龍太被弾v5とカバン予備を維持。全身1枚の紙人形方式と既存生成素材を使い、必要な新しい風船／地雷／罠などの生成・採用を明示する。
