# ペープサートの基本モーションと開始・決着（2026-10-15）

共通方針docs/PAPER_THEATRE_DIRECTION.mdとユーザーの追加指示を実装する。関節分割／ボーンを導入せず、キャラ全身Spriteの回転・移動・スケール・停止を固定tickの段階変化で使う。千鶴は現行の紙全身素材、透真／蓮は素材制作の停止指定を守り、新規原画を勝手に制作しない。

1. 既存ヒットストップ／前進／後退／開始・リザルトフローを確認し、あるものは重複実装しない。
2. 紙キャラの攻撃は引く→前に出す→短い戻り、軽被弾はのけぞりと戻り、吹っ飛びは絵全体が中心でくるくる回る。勝利は少しだけ得意げな段階動作。歩き15度／走り45度固定は維持。描画はAgeから決め、描画回数やTimeで勝手に進めない。物理・攻撃性能は変更しない。
3. ステージ／登場／間→FIGHT!→操作可、決着停止→KO!→勝敗演出→リザルトを既存フローに沿って補う。勝者と敗者のポーズが見えること、開始中の入力を持ち越さないことを検査。
4. 大きい紙の効果・紙吹雪等、工作舞台と縮小装置は既存演出との差分を確認。素材追加が必要な大きい背景変更は現行の攻撃原画比較と分けて進め、完了を偽らない。
5. カバン版は削除指示まで保護。フライパン12原画は横／上下各3段×予備と有効の2枚として比較制作し、未選択の案をゲームへ自動採用しない。
6. 意味のある固定tickと実Renderer／フローのテスト、実Unity全4工程、実描画画像を確認。合格後に通常commit・pushし、RESUME／STATUS／引き継ぎへ実件数と未完を記録する。
