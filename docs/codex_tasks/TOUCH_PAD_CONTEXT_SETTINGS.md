# 戦闘とメニューでのタッチ移動方式（2026-10-25）

所有者指定：戦闘はバーチャルスティック、戦闘以外は十字キーを初期設定とし、設定からそれぞれを変更可能にする。

- 戦闘（練習を含む）と開幕カウント中は「戦闘中」の指定。タイトル/選択/ポーズ/設定/リザルト等は「戦闘以外」。
- 戦闘中と戦闘以外の方式を独立して「スティック」「十字キー」から選び、端末へ保存。未設定の既存ユーザーにも上記既定値を適用。
- 配置編集/大きさ/不透明度の保存を維持。移動パッドのカスタムを引き継ぎ、方式変更や画面切替で方向押下を残さない。物理パッドの割当も維持。
- UI入力/描画だけを変更し、戦闘コード・数値・原画は変更しない。
- 実Unity4工程とタッチ方式切替/メニュー移動/長押し解除/保存再読込を検査。Windows/WebGL/Androidへ反映し、区切りごとにRESUME/STATUSへ記録する。
