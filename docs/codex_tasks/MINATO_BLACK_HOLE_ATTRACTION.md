# 湊の超必殺：ブラックホールの強い引力（2026-10-19）

## ユーザー指定

ブラックホールへ対戦相手が吸い込まれる挙動を追加する。接触後のハート2つ減少は維持する。新規イラスト生成や他キャラの性能変更は含めない。

## 実装順

1. 現在の持続する静止飛び道具と、接触時の既存ダメージ／防御／多重ヒット防止を確認。
2. 純C#の固定tickで、敵の持続場から中心方向への継続的な外力を計算する。自分・範囲外・消滅後・同じ攻撃の接触処理済み相手・被弾後の保護状態には適用しない。ヒットストップとカットインを尊重。
3. 外力は通常の足場AABB衝突処理へ通し、壁や床を通り抜けさせない。入力と重力に別の移動成分として合成し、範囲外へ出た後に余分な速度を残さない。左右と上下から吸い寄せる。
4. 範囲と引力速度はAttackDataのAbilityデータで調整可能にし、湊の既存アセットへ一度だけ移行する。反復BuildAllで調整値を戻さない。静止場の位置・大きさ・180tick寿命・ダメージ2・攻撃IDによる1回判定を維持。
5. EditModeで左右／空中／離れる入力／範囲外／一度だけ2ハート／持続終了・置換／自分と他の飛び道具への非干渉／防御・停止／決定性・地形衝突を検証。PlayModeで実キーの湊超必殺から吸い寄せて2ハートになる流れと表示を確認。
6. Unity全4工程を実行し、Web版を更新して実ブラウザも確認。STATUS・RESUME・実装順・バランス記録を更新し、全合格後に通常commit/push。
