# 8種類の即時発動サポート（2026-10-21）

親指示書：SUPPORT_ITEMS_LEDGE_AND_PAPER_HUD.md。ユーザーが出現間隔・効果の仮設定を承認済み。先に紙HUD、次に崖つかまりの区切りを完了し、その後この工程を進める。

## 確定した初期ルール

- 本4種、カード2種、銀・歩各1種。拾った瞬間に発動して所持しない。
- 初回8〜12秒、以後10〜16秒、場の主アイテムは1個まで。本人の取得CD10秒中は拾えず残る。
- 8種シャッフル一巡まで重複なし、次の袋の先頭も直前と同じものを避ける。純C#の固定seed疑似乱数で再現可能にする。
- ALMA：全画面に青白い意識フィールド。相手の移動・ダッシュを5秒間60％、攻撃速度を変更しない。
- 志遠の車：赤い小型オープンカーで異次元から登場して横断。命中2秒麻痺、ハート直接減少なし。
- 咲と花：もやしカレーで5秒ST無限。通常/防御/移動/崖の消費を免除、崖の時間上限は維持。
- 紗良：救急箱で1ハート回復、最大ハート超過なし。
- 舞依：弓道着から矢を放つ。命中1ハート、所有者免疫、防御と多重ヒット防止は既存共通処理を使用。
- 剛：水着で登場して財布を場内のランダム位置へ。財布は双方が拾えてST全回復。
- 美桜：5秒または通常3回/特殊1回分を吸収するバリア。超必殺は貫通。耐久不足時の余剰ダメージは与えず、その1回を防いで解除。
- 歩太：歩へ変身、上空からランダムに6個落とす。相手だけに各ST15減少、ハート直接減少なし。

## 実装構造

シミュレーションはSupportDefinition/SupportSystem/SupportStatusへ分離し、配置・取得・CD・NPC登場・投射・効果期限を60Hzで決定する。数字はBattleRulesのSO経由。既存単体テスト用の旧ルールは既定で無効、製品ルールへ一回移行して有効化。ラウンド・再戦時に全効果と拾得物をリセットする。停止・カットイン中は余分に進めない。

攻撃は専用AttackInstanceを発行し、使用キャラのAttackや入力状態を書き換えない。通常の射撃ST費用を追加徴収しない。車と矢は既存防御・所有者除外・同一攻撃の1回命中を共有する。歩の落下は下方向なので崖つかまりにもSTダメージを与える。財布は主アイテムと別枠で短時間残し、場外や固体内部へ配置しない。

描画は生成済み候補art_source/paper_support_items/の8組と6道具を審査して取り込む。既存生成カード裏面・次元の裂け目を再利用。原作参照はdocs/art_reference/support_items/sources.json、外観は独自に推測確定しない。本作のクロスオーバー演出と明記。PNG原本を保持し、透明梱包以外に再サンプルしない。

紙HUD内に本人の取得CDを表示し、ST無限・スロー・バリア残りを状態札へ示す。大きい演出は戦闘キャラを隠しすぎない。ALMAの薄い青白フィールドはUIを着色しない。
