# 次工程：切り紙エフェクトと工作舞台

着手前にAGENTS／RESUME／IMPLEMENTATION_ORDERを確認。同時編集禁止。順1〜4の開始・結果・全身動作と順6の音はpaper_theatre_2で実Unity合格。フライパン12原画は比較用、採用未決。これを勝手に接続しない。

1. 最初は紙のヒット演出だけを実装。既存BattleEffectsView／BattleFeedbackを読み、衝撃、切り絵の放射、紙片をパッと出す。弱い通常／特殊／コンボ終段／ジャストのシルエットと強さを区別。既存のヒットストップ／フラッシュ／揺れを再利用し二重化しない。
2. エフェクトの位置はヒット時点で固定するか、接触中だけ追うかを明記。退いた相手へ衝撃が延々ついていかない。プール上限、数値は表示SO、停止／再戦時に消去。純C#シミュレーションは変更しない。
3. 実Unity全4工程・実描画・短い報告で区切る。合格後に通常commit／push。
4. 次に3ステージを工作舞台へ。既存作品別背景を参考に舞台幕、厚紙の縁、重なり、支えを追加。カメラ範囲／足場の視認性を維持し、地形・場外・縮小の戦闘数値は維持する。第三者画面の複製や別ゲームへの書き込みはしない。
5. さらに縮小時の舞台装置が閉じる見せ方。判定の予告／消失tickと視覚を一致させ、紙吹雪等で足元の危険を隠さない。各小工程ごとに検証とRESUMEを更新。
