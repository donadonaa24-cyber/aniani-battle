# 千鶴をフライパン版へ切替（2026-10-15）

ユーザー「ゲーム内をフライパンにして」。比較からゲーム採用へ進める。カバン版の原画／全文条件／バックアップは削除しない。新規の大量生成は行わず、既存の横振り／上下振り2コマを全身Spriteとして使う。

1. 地上通常は横振り1段→横振り2段→最大の上下振り3段。各段で発生前の溜めと有効以後の打撃姿勢を切り替える。3段目は持ったまま振り下ろし、カバン投げを残さない。
2. しゃがみ／後方／空中のカバン姿勢もフライパンの2原画へ切り替え、同じ全身絵を方向別の傾きで使う。本人の左手で持つ。紙枠1304×1450／共通PPU／靴支点を維持、原画をポーズごとに独立拡縮しない。
3. 通常3段目を絵に合う近接判定へ。発生・持続・硬直・ダメージ・前進は維持し、投げに固有の処理だけ外す。旧カバン設定は復元可能に保存。その他の技の戦闘性能を変えない。
4. 採用対応表と日本語確認フォルダを更新し、予備／未使用案と現行を区別。頭・靴・手の絵の最終審査残は明記する。
5. 2コマの切替／保持、3段の判定、カバン非表示、双方スロット、共通枠／画素一致／予備SHAを検査。実Unity全4工程、実描画を確認し、合格後通常commit／origin mainへpush。RESUME／STATUS／実装順を更新。
