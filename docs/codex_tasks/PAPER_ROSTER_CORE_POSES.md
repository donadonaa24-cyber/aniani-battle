## 白い切り抜き縁の品質（2026-10-15 ユーザー指摘）
- **原因（2026-10-15 確認）**：内蔵 image_gen に「透明背景で出力」させると、切り抜きの境目が柔らかい半透明（フェザー）で出ることがあり、白い縁の外側がぼやける（待機v2はたまたま硬く、ガードv1は柔らかかった）。
- **推奨の作り方**：透明背景で直接出させず、**肌色・クリーム白・衣装色から遠い単色の背景（純緑 #00FF00 または純マゼンタ #FF00FF、キャラの配色で選ぶ）で生成** → その色をキー抜き → **アルファを2値化**（α≥128→255、<128→0）→ 縁の色かぶり（緑/マゼンタのにじみ）を除去してクリーム白に揃える。人物画素は再サンプルしない。キー色・しきい値・処理前後を manifest に記録。
- 既存の採用絵（待機9人・千鶴・透真）も、縁の外側に半透明帯が残っているものは同じ2値化で直す（人物内部・線画は触らない。元画像は保持）。
- 白い縁は残す。ただし**ぼやけ・にじみは不可**（透真のガード v1 は縁が太く外側へグラデーションでにじんでいた。待機 v2 の細くくっきりした縁が基準）。
- 採用前の検査：縁の外側の半透明帯の幅を測り、待機 v2 と同程度（目安 2px 以下）であること。超える場合は作り直す。
- 作り直しが難しい場合の後処理：人物の画素は再サンプルせず、**外周の半透明画素だけ**を、アルファしきい値で2値化（例：α≥128→255、<128→0）し、縁の色をクリーム白に揃える。人物内部・線画には触れない。処理前後を保存し、処理したことを manifest に記録する。
