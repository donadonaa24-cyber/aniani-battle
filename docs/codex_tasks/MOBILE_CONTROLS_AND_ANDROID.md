# 半透明の仮想パッドとAndroid APK

2026-10-23追加依頼。無料オンライン・ホーム/ポータル・紙ガチャの公開を完了しつつ、スマホ用の半透明操作とUnityのAndroidビルドを制作する。

## 実装すること

1. 現在の入力・メニュー・UIモジュールと、Unity付属Android環境を確認する。有料サービスやストア契約、個人の署名鍵は追加しない。
2. 左下へ方向、右下へ通常/特殊/ジャンプを主に配置し、ガード/回避/カウンター/超必殺/ダッシュも押せるようにする。中央の戦闘と上部HUDを空ける。紙の雰囲気に沿う半透明台紙、押下中の濃いフィードバック、複数タッチ、長押し/離して発動、キャンセル・フォーカス喪失時の解放を実装。
3. メニューでは方向と決定/戻るを使えるようにし、戦闘用の補助ボタンは整理する。モバイル自動表示とPC検査用の表示切替を用意する。物理キーボード/ゲームパッドを壊さず、オンラインのローカル入力P1にもそのまま接続する。
4. 横持ち基本、セーフエリアと小画面を考慮。縦持ちは横持ちを案内する。操作キャラへボタンが追従する配置にはしない。技の値は変更しない。
5. Unity実4工程と実ブラウザの表示/移動/攻撃/長押し/メニュー/切断を検証。Androidはインストール済みSDK/NDK/OpenJDKを利用し、まずARM64のAPKを作る。署名・中身・ABI・起動対象を確認。実機がない場合は実機未確認と明記する。
6. WebGLを再ビルドし、公開用静的分割とポータルの対応案内へ反映。Android APKはまずローカル成果物として渡す。Play Store登録や個人署名鍵、有料サービスは行わない。ネイティブAndroidの招待通信は別対応であり、WebRTC招待はブラウザ版の機能として説明する。
7. 最新のRESUME/STATUS・検証証跡・次の手順へ引継ぎ、合格した区切りを通常commit/pushする。

既存の崖A・龍太承認被弾v5・保護カバン・半減45判定・14/10ゲージ・戦闘数値・Free構成・既存159枚/ガチャ所持を保持する。
