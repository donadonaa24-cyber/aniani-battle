# R5：生成した舞台と9人集合の選択画面

既存PAPER_STAGE_ILLUSTRATIONSと最新SPEC_REVISION_20261016に従う。R4までの人物とチーム状態を保ち、舞台・トップ／選択の絵を生成して取り込む。

3作品の舞台は星の終わりの青紺SF・管理AI／未来都市、推し駒Battleの6×6将棋風盤面と駒／塔、Battle à la carteの文化祭調理場と屋台／黒板／料理。幾重にも貼った厚紙・ハリボテ・工作舞台、奥行きの異なる平面レイヤー、控えめな視差で表現する。足場とギミックの絵も生成して取り込む。人体と攻撃・被弾カウントを隠す飾りや、立体3D世界への変更は避ける。

共通のメイン足場1・上部すり抜け足場2・左右／下の場外線・縮小判定を維持。見た目だけ電子消失／盤面消失／片付けへ変える。落ちた瞬間の敗北にはせず、復帰余地を維持。画像の縁を理由にコライダーを動かさない。

集合絵は採用9人が主役、3作品ごと3人ずつのグループで戦っている構図。透真が看板主人公。各人の顔・全身・選択位置が判別できる構図、人物の混成や欠員を審査する。サポートは同3作品の確認済みの仲間のみ背景へ控えめに。未確認の仲間を勝手に正史として足さない。

トップとキャラ選択は同じ集合イラストを参照。生成された文字へUIを依存させず、作品名・人物名・3枠の選択順・選択カーソル・重複不可をUnityで表示する。R2の上下左右グリッドとプレイヤー3→CPU3の流れ、取り消しを維持し、人物の見え方に合わせた選択位置を設定する。選択のためだけに別の集合絵を生成しない。

原画・全文プロンプト・ライセンス／自作情報・採用版と生成工程を記録する。画面比率3種でカメラ／盤面の背景が収まり、戦闘結果が変わらないテストの意図を維持。実Unity全4工程・画面証跡を保存し通常保存。
