# R6：WebGLとローカル実動

既存WEBGL_BROWSER_BUILDの手順を参照し、R5までの同じゲームをWebGLへビルドする。Unity6000.6.0f1のWebGLSupportは導入済みを確認している。Windows版の全4工程も維持する。

ブラウザのキー／パッド、上下左右のチーム選択、決定・取消・FIGHT解除後の操作、ポーズ・再開、音量設定、勝敗と次ラウンドを確認する。デスクトップ専用の全画面／終了表記はブラウザ用へ適応する。入力フォーカス・音声のユーザー操作開始・リサイズを実ブラウザで検査する。

Editorの再現できるビルド入口とローカル配信手順を保存。圧縮形式とHTTPヘッダーの必要条件を設定し、誤ったcontent-typeやgzip／brotli配信で起動不能にしない。ファイルを直接開いたことをWebGL検証と呼ばず、ローカルHTTPから起動する。

ビルドはサンドボックス外のUnityを使い、-nographicsを付けない。ブラウザ操作には該当スキルを読み、実画面と実入力で確認。実行時エラー・ビルドサイズ・起動方法・実動スクショをRESUMEへ。必要なサーバーをバックグラウンドで開始する場合は非表示にする。

この工程はビルド実装とローカル確認。ユーザーの別途許可なしに外部公開・ポータル変更・他プロジェクト書き込みをしない。全4工程とWebGLの合格後、秘密情報を含めず通常commit・push。
