# R2：順番チーム戦と選択・設定画面

SPEC_REVISION_20261016のチーム回答を実装する。R0とR1の受入後に着手。

純C#のチーム状態でP1／相手の3人、選択順、得点、ラウンド番号、重複拒否と取り消しを管理。ラウンド1は各チーム1番目、2は2番目、同点なら3は3番目。2勝で終了。引き分けは得点せず同じ出場者で再試合。各ラウンドはBattleSimulationを新規生成し、ハート／タイマー／ゲージ／状態／場外を初期化する。

選択はP1の3人→CPUの3人。相手チームとの同キャラは可、チーム内は禁止。上下左右で9人のグリッドを動かし、上キーを対象切替に使わない。決定で追加、戻るで直前を取り消す。CPU側0人で戻るとP1の最後を戻す。2人対戦も順番でチーム編成する。練習は素早く試せるよう各1人とし、チーム戦にしない。

CPU難易度は設定画面へ移し、キャラ選択の上下に紛れ込ませない。トップの主要項目はCPU対戦／2人対戦／練習／設定／終了。音量・FPS・画面揺れ・キー・ダッシュ・ヒント・判定表示・CPU難易度・操作説明／チュートリアルは設定へ。ポーズからも設定へ入って戻れる。

ラウンド結果は今回の勝者・敗者とチーム得点を表示し、未決着なら次ラウンド、チーム決着なら再戦／編成／タイトル。再戦は同じチームの順番で1ラウンド目から。専用絵の勝敗とFIGHT／KOを再利用する。

作品別グリッドはR2で入力を完成させる。トップと同じ生成9人集合の使用はR5で差し替える。絵の差し替えでチーム状態や選択対象を変えない。

単体検証：重複／取消／両チーム／2-0／2-1／引分／再戦／各ラウンド初期化。実UI検証：P1を3人決定→CPU3人→ステージ→FIGHT→各ラウンド→チーム結果、上下左右／戻る／設定往復／ブラウザ用表記。実Unity全4工程と証跡を保存し通常commit・push。
