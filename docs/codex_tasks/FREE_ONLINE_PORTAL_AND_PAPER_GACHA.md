# 無料オンライン対戦・ポータル公開・紙素材ガチャ

2026-10-22 所有者依頼。Supabaseを有料にせず通信対戦を実装し、ホームページとあにあにポータルを更新・公開する。今回の紙キャラとサポート原画を既存ガチャへ追加する。他プロジェクトへの今回の編集・公開は、この依頼による許可範囲で行う。

## 順序と完了条件

1. 既存公開用ポータル、共通基盤、GitHub Pages、Supabase Freeの現設定を読む。課金・アドオン・有料中継を導入しない。既存の共通SQLを再適用しない。
2. Webブラウザ対戦の無料設計を実装。Supabaseは人数制限付きの部屋・接続交換に限定し、試合入力はWebRTC DataChannelで直接通信する。有限の接続待ち・部屋寿命・再接続回数・送受信量上限を設け、接続不可時は無料のまま終了案内する。非公開の部屋IDと参加権限を検証し、無制限のDB記録や毎フレームのRealtime送信を避ける。
3. 両端で同じ入力順・乱数・キャラ/ステージ/ルール版を使う。入力待ち・切断・同期不一致を明示し、入力を捨てて試合を継続しない。既存ローカル対戦・練習・3人チーム・戦闘数値を保持。オンライン結果からクライアント申告で共通コインを発行しない。
4. あにバトの公開ホーム/ブラウザ版とポータル紹介を紙素材・現在9人/3作品/チーム戦/サポートの内容に更新。WebGLの読み込みはクリック開始、画像とゲームは静的配信しSupabase Storage帯域を使わない。実装済み/試験版/接続条件を正確に表示する。
5. 公開用無料試験ガチャへ紙待機9人とサポート8組のカードを追加。既存159枚のID・所持保存・データ・レア率を保持し末尾追加。共通コインガチャとは統合しない。画像は採用原画からWeb向け派生画像を作り、生成AI使用を明記。既存演出と図鑑へ接続する。
6. 純C#通信契約の検査、Unity全4工程、WebGL、実ブラウザ2端末相当の対戦・切断・無料制限・PC/スマホ幅のポータルとガチャを確認。公開前に秘密情報と差分を確認し、通常commit/pushと公開URLの実動確認まで行う。実回線間の接続は同一PC検証と区別する。
7. RESUME/IMPLEMENTATION_STATUSとポータルのCURRENT_STATE/CHANGELOGを更新。実施済み・SQL適用/公開状態・検証証跡・未確認事項を分けて記録する。

## 制約

有料プラン変更・有料アドオン契約なし。個人情報や認証情報をGitへ保存しない。Supabase Freeの制限によるサービス停止と課金を混同しない。TURNを必要とする回線で接続できない場合を明記する。崖A、保護カバン、龍太承認被弾v5、45半減判定、14/10ゲージと既存戦闘値を維持する。
