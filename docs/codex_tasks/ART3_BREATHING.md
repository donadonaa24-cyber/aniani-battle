# ART3B：新待機絵の呼吸アニメ・ゲーム接続（2026-10-12）

## ユーザー依頼

ART3で生成した透真・蓮・千鶴をゲームに実装できるよう、待機中の体が縦に揺れて呼吸するピクセルアートを作る。今後もすべて同じサイズにする。

## 固定する制作規格

- 全キャラ・全アニメの1コマは224×160px、透過PNG、足元y=159、PPU50、pivot(0.5,0)。画像内の余白も含むセル規格として統一する。
- キャラの既存の身長差は透真124px／千鶴112px／蓮100pxを基準に保持する。呼吸の上端は基準±1〜2px、足は接地したまま。フレームごとの全身の拡縮は禁止。
- 固定ピクセル格子・32色以下・二値アルファ、Point/no mipmaps/no compression。今後の生成プロンプト・加工・検証で同じ規格を使う。

## 作業

1. 内蔵image_genでART3の1枚絵を参照し、同一人物・同じ向き/足位置/衣装の小さな呼吸キーポーズを生成。原画・最終プロンプトを新しい場所へ保存する。
2. SpriteForgeで規格へ加工し、体の上下動が読める8Fの滑らかなループを作る。足元・倍率・色を一定にし、前後絵のブレンドやゴーストを使わない。生成原画の細部が揺れる場合は単一キーから整数ピクセルの呼吸を作り、顔/衣装を固定する。
3. 新idleをAnimationSetへ接続し、頭上カウンターのheadHeightsを更新。既存の他アニメと戦闘性能は保持し、BuildAllのTiming/独自調整保持を維持。
4. 同じ制作規格の文書と再生成/検証スクリプトを保存。新しい待機絵を変更する前の原画・出力はGit/保存元から追跡可能にする。
5. GIF・コマ一覧を自分で確認し、サイズ・足位置・倍率・上下動・色数・alpha・再生成一致を検査。必要なUnityアセット/シーン回帰を確認する。
6. tools/verify/run_unity.ps1 -Tag art3bを外部承認で実行し、BuildAll/EditMode/PlayMode/Windowsビルド全合格を確認。実キー撮影を行う場合は事前に必ず「PCに触らないで」と声をかける。
7. STATUS/RESUME/ASSET_SOURCESと最終報告を更新。全合格後にcommit・origin mainへ通常push。同時編集禁止、アサーションを弱めない。

## 未確定として残さないもの

今回の対象は待機アニメ。その他のモーションを新絵柄へ描き直す作業は含まない。共通セル/倍率/足位置の規格は今後のすべての素材に適用する。
