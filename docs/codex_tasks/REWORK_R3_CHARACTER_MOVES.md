結一は既存名の結衣として扱う。原作未確認の効果を正史として説明しない。超必殺を任された3人の案はSPEC_REVISIONにも記録済み。

戦闘は純C#、Unityは表示のみ。瞬間移動・上昇下降・頭上からの落下・場に残る判定を必要な最小単位の処理に分け、攻撃定義から使う。瞬間移動は舞台／場外を無視した座標固定を避け、狙った位置・移動先と失敗条件をテストする。残留判定・複数の部下や演出があっても同一攻撃インスタンスで同じ相手へ多重ダメージを入れない。

追加6人の共有技を本人用のアセットへ分離し、共有先を編集して他キャラまで変更しない。既存45件の半減判定は原アセットに保持。新武器へ置換する技は新アセットとして参照を差し替え、旧技を削除しない。千鶴のフライパンとおにぎりの既存原画・寸法、カバン予備13原画を保護する。

通常は既存の各段の前進と通常1発分の蓄積、特殊は通常と異なるハート処理、超必殺は既存のゲージ・回数・ハート処理を維持。新しい技の数値はアセットに明記し、説明だけで追加のダメージ／無敵を導入しない。練習の超必殺無制限も維持。

受入：全9人の独立した定義と参照／武器、各技の発生・有効・硬直、移動と端、飛び道具寿命、同一攻撃の多重防止、ガード・回避・カウンター、通常相殺、CPUと練習の入力。R4の未制作絵は仮表示と明記し、固有技の実装と原画完成を区別。実Unity全4工程の後に通常保存。
