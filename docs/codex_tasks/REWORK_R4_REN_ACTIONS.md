## 制作するもの

- 通常1段：前へ飛び込む頭突き。予備は体軸を引き、当てる絵は頭から前へのめり込む強い決めポーズ。
- 通常2段：頭を地面につけたカポエイラ風の回転蹴り。腕と頭で支え、両足の役割と回転が読める。肩・首・腕のつながりを省略しない。
- 通常3段：腕で地面を押し、前方へ両足蹴り。最大の予備と最大の当てる絵。頭突き→逆立ち→両足のつながりを見せる。
- 地上上：上へ蹴り上げる明快なシルエット。地上下：腰を落とした低い蹴り。地上であることを絵でも区別する。
- 空中N：両脚が地面から離れた蹴りの構え→前方の蹴り。方向別の空中攻撃や空中停止を復活させない。
- 特殊：本人の飛車への変化の構え→飛車の紙駒の突進姿。人の頭・靴を持つ姿勢との寸法審査と、駒へ変わる姿の審査を分ける。
- 超必殺：本作独自の連続飛車突進。本人の強い構え→飛車の決め姿。原作に未確認の設定を正史と呼ばない。
