# 操作・HUD・カメラの表示設定

設定 → **操作・HUDの配置**で編集する。Windows・Web・Androidで同じ機能を使用する。

- 左下はスティック。中心付近は入力なし、指を動かした方向へ移動。指を離すと停止する。
- 右下の丸ボタンはジャンプ・通常・特殊・防御・回避・反撃・超必殺。方向＋特殊や、通常の長押しも従来どおり。
- 編集中は試合が停止する。各操作やP1/P2ステータスをタップして選び、ドラッグで移動する。左右の選択ボタンからも選べる。
- 大きさ50～200％、不透明度15～100％を調整する。画面の外へはみ出す配置や倍率は収まる範囲へ制限する。
- **保存して戻る**で端末内に保存。**変更を破棄**で編集開始時へ戻る。**初期配置へ**は編集中の配置を初期化し、保存するまでは確定しない。
- HUDの既定サイズは旧版の約2倍。HUDを50％にすると旧版と同程度の大きさになる。
- 保存は`AniBato.UiLayout.v1`。ブラウザや端末のローカル保存なので別端末へは同期しない。

## 残像を元に戻す

設定 → **残像 OFF（元の表示）**。ダッシュ・通常攻撃に最大2枚/約0.1秒の薄い残像を足す表示だけの機能で、OFFでは元の体の描画へ戻る。瞬間移動・被弾・崖つかまり・再戦では残像を持ち越さない。

## 瞬間移動カメラ

湊・シロ等の瞬間移動技を受け付けた時点から、行き先に関係なく約0.4秒で舞台全景へ引く。技の終了後も約0.5秒保持し、緩やかに戻る。移動した瞬間の座標で急拡大する処理をこの演出中は使わない。移動距離・発生・判定・戦闘結果は変更しない。

旧公開版はGitHub Releasesの`v0.1.1-trial.20261023`（Windows）、`v0.1.0-trial.20261023`（Android）を保持する。
