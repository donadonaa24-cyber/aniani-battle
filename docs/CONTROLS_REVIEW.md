# 操作体系の見直し（フェーズ6A・2026-10-12）

分かりにくさの主因は、8つの戦闘ボタンを最初から覚える必要があること、左右2回と専用ボタンの両方でダッシュが出ること、特殊の方向入力とキャラの向きが別の概念であること、対戦画面に長い操作表が常時表示されることだった。

実装した改善は、練習・14段階チュートリアル・2ページの技表、最後に触った機器に合わせた表記、現在の割り当てを参照する説明、P1/P2・機器別キーコンフィグ。技表はキャラ選択のTab/SHAREとポーズから開く。対戦中の基本ヒントは開始5秒だけ、ポーズからOFF可能。練習の相手・ハート固定・時間固定もポーズから変更する。

方向通常はキャラの向き基準。空中移動・2段ジャンプ・ダッシュ・特殊・超必殺で向きを変えない。地上の下入力はしゃがみ、上足場は18F長押しで降下。斜め前上/下は両軸0.45超で判定する。急降下の操作は従来どおり下入力。特殊は上/下→横→方向なしの優先順を保持する。

キーコンフィグの重複は、同じプレイヤー・同じ機器内で既存ボタンと入れ替える。P1/P2の設定は独立で、別プレイヤーとの重複は許容するため、2人で同じキーボードを使う場合は別キーを選ぶ。変更されたPrimaryの旧Alternateは無効になり、初期化で復元する。保存先はPlayerPrefsのみ。メニュー決定/戻るはパッド南/東に固定、ポーズは変更可。Escは設定中の取消、F9/F11/Tabは共通機能のため新規割り当て対象から除く。パッドのアナログ移動は維持し、ボタンによる方向操作は変更可能。

6B採用：左右2回入力のダッシュON/OFF（既定ON、両者共通）をメニュー・ポーズ・キーコンフィグに追加。OFFでも専用ボタン有効。保存値をtick入力へ含め、切替時に古い自動ダッシュ予約を消す。操作説明・技表・チュートリアルも現在の設定を表示。実DualSenseの使用感はClaude/ユーザーの実機確認待ち。

今後の提案（PHASE6Bでは採用しない。実機の感想待ち）：

- 初心者向けプリセットで防御3種類の学習順を選べるようにする。入力ボタンの統合は相性とジャスト操作へ影響するため今回は行わない。
- ガード・カウンター・回避を一括で比較できる短い動画/図を技表へ加える。現段階ではチュートリアルの実操作で学習する。
