# サポートアイテムと戦闘表示

## 拾い方

本・カード・銀・歩に触れると即発動。持ち物として保管しない。初回は開始8〜12秒後、以後10〜16秒間隔、場の主アイテムは1個まで。本人の再取得待ちは10秒で、その間に触れてもアイテムは残る。8種類が一巡するまで同じものを出さず、次の袋の先頭も直前の品を避ける。ラウンドごとに効果・配置をリセットする。

| 見た目 | 登場人物 | 効果 |
| --- | --- | --- |
| 本 | ALMA | 5秒、相手の移動速度60％。攻撃速度はそのまま。世界が淡い青白色になり少し歪む |
| 本 | 志遠 | 赤い車が横切る。当たった相手は2秒マヒ |
| 本 | 咲と花 | 5秒スタミナ消費なし。崖つかまりの最大時間は延長しない |
| 本 | 紗良 | ハート1個回復。最大値は超えない |
| カード | 舞依 | 相手へ矢を放ち、命中でハート1個減少 |
| カード | 剛 | 場内に財布を落とす。先に触れた人のスタミナが全回復。財布は再取得待ち中でも双方が拾える |
| 銀 | 美桜 | 5秒、または通常3回・特殊1回分を防ぐまでバリア。超必殺は貫通 |
| 歩 | 歩太 | 上空から歩6個。相手に当たるたびスタミナ15減少 |

攻撃するサポートは持ち主に命中しない。車のマヒと歩のスタミナ減少はハートを直接削らない。上記はユーザー承認済みの仮バランスで、BattleRules.Supportから調整できる。

## 表示

- 取得直後は画面下部に取得したプレイヤー・人物名・効果・秒数を4.5秒表示。双方が続けて拾っても別々に表示。
- 名前横のアイコンは各本人の採用待機原画。日本語名の上は英語ルビ。
- STはスタミナ、LINKは超必殺ゲージ。下の小札は特殊各方向の再使用待ち。台紙・札全体は旧版の約3分の1。
- 頭上の`0/3`は通常攻撃の被弾蓄積。黒い台紙と文字の影を除き、数字だけを表示する。
- 試合カウント中、両キャラは共通の生成済み次元の裂け目から登場する。FIGHT!が消えるまでは戦闘操作を受け付けない。

透真のロケットは上部の足場・設置壁を通過してメイン足場で爆発する。溜めによる爆発範囲拡大とハート2個の単発ダメージは維持する。

現在採用の原画は`イラスト確認/ゲーム採用/アイテムサポート/`。過去候補は`イラスト確認/生成履歴/`へ分離。ゲーム接続・動作確認と美術のユーザー最終承認は区別する。最新の実検証は`docs/codex_logs/paper_support_verification.json`を参照。
