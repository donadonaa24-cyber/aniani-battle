# 生成した紙舞台と9人集合（R5）

指示：codex_tasks/COMPLETE_R5_R6.md。原画生成は内蔵image_gen、主役は既存の9人の採用待機を直接参照。第三者のゲーム背景・人物・UIは取り込んでいない。

## 3つの舞台

各作品7レイヤー、合計21を採用。遠景・中景・舞台枠・メイン足場・小足場・縮小予告・縮小小物。採用版・原寸・全文条件・SHAはart_source/paper_stages/manifest.json、ゲームで使用する領域は同runtime-manifest.json。参照した舞台同士の画風を継承して制作した本作独自の工作舞台。

将棋盤の生成格子は6列5行となったため不採用。中景v3の無地の木板の上に、その生成原画から切り出した36の木目セルを置き、正確な6×6を描く。旧候補は原画資料として残し、ゲームへ取り込まない。

生成足場に混ざった建物はSpriteのUV領域から除外する。天面を実判定のTopへ一致させ、厚みを下側へ描く。縮小では元画像の対応部分を切り出し、消える左右部分を12片へ分けて表現する。未来都市は消失、盤は反転落下、文化祭は片付けの落下。元PNGの画素は無加工。生成小物の半透明のにじみは描画shaderのアルファしきい値0.8で除外する。PNG自体のアルファを書き換えたものとは区別する。

StageView／GeneratedStageScenery／GeneratedPlatformViewはシミュレーションを読み取るだけ。3作品共通の地形・通り抜け・場外・縮小時刻・攻撃性能を変えない。背景の視差は控えめ。遠景はカメラを覆い、舞台枠は外周へ寄せる。

## 9人の集合絵

原画はart_source/title_paper/。9人の採用待機→作品別の3人集合→9人の横長集合、の順で内蔵image_genを使用。manifest.jsonへ全4原画と参照のSHAを保存する。透真は中央、左が推し駒、右が料理。人物は普通のアニメ塗り、白縁と棒、背景が工作舞台。

未確認のサポート人物の容姿は追加していない。小さな管理AI風の窓／電子小物や将棋駒／料理小物は本作独自の背景表現であり、未知の人物や正史の設定ではない。サポート機能の実装完了を意味しない。

トップと選択はPaperEnsemble.assetの同じArtwork Spriteを共有する。選択では同じ原画の顔周辺をUVで切り出し、元の位置へぴったり重ねて明るさと選択枠を表示する。別の顔絵への差し替えではない。9領域は重複せず、名前／作品名／選択順はUI。上下左右の作品グループ移動、P1→CPUまたはP2、各3人、同チーム内重複禁止を保持する。

再現：Nodeでtools/verify/prepare_paper_stages.cjs、audit_r5_art.cjs → Unity BuildAll。生成サービスからの再生成は不要。SHA不一致はエラーとし、原画を上書きしない。
