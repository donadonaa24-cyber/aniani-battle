# チーム戦と画面（R2）

直近の合格結果はRESUME冒頭とrework_progress.jsonを参照。

## 選択から試合まで

トップはCPUチーム対戦／2人チーム対戦／練習モード／設定／終了。

チーム戦はP1の3人を順に選び、その後CPUまたはP2の3人を選ぶ。上下左右で作品別の9人グリッドを移動し、決定またはイラストのクリックで追加する。同じチームで同じキャラは選べない。相手チームと同じキャラは選べる。

CPUチームもP1の操作で選ぶ。2人対戦はP1編成中はP1の操作、P2編成中はP2の操作。取消は直前の1人を戻し、相手側がまだ0人ならP1の最後へ戻る。何も選んでいなければトップへ戻る。ステージからの取消も最後の1人を戻す。

6人を決めるとステージ選択へ。ラウンド1は各1番目、2は各2番目、3は各3番目が出場する。先に2勝でチーム決着。2対0なら3戦目を始めない。引き分けは得点せず、同じ出場者で同じラウンドを再試合する。

各ラウンドでハート、被弾蓄積、ゲージ、使用回数、状態、タイマー、位置、足場と縮小を新しくする。勝ったキャラの居残りや次のキャラへのダメージ引き継ぎは行わない。FIGHT!が消えてから操作開始し、決着後の結果で次ラウンドへ進む。チーム決着後の再戦は同じ編成の1番目から。

練習は各1人を選び、チーム戦にしない。練習の満ゲージと超必殺無制限はR1のまま維持。

## 設定

BGM／SE音量、フレームレート、画面揺れ、開始ヒント、左右2回ダッシュ、攻撃判定表示、CPU難易度、キーコンフィグ、操作説明、チュートリアルを設定画面へまとめる。

ポーズからも設定へ入り、設定や操作説明・キー変更中は試合を止める。設定からポーズへ戻り、再開操作で復帰する。CPU難易度の変更は次の試合から反映する。

## 原画の残り

R2は選択と試合進行の工程。作品別の9人待機イラストを引き続き使う。トップと選択で共通の9人集合絵を使う変更はR5、最新の各人の固有技はR3、その専用原画はR4。現在の試作・仮表示を原画完成と混同しない。
