# 現在の攻撃操作（2026-10-16、R1）

最新の実Unity全工程の結果はRESUME冒頭とrework_progress.jsonを確認する。本書はR0・R1の操作と仮表示をまとめたもの。9人固有技の最新案・専用原画・チーム戦は後続工程であり、ここで全体完成とは呼ばない。

## 通常

- 地上の通常は短く押して離すと発動。次の押下で3段までつながる。
- 上＋通常は上攻撃、下＋通常はガードを崩す下攻撃。背後＋通常は従来の背面攻撃。
- 地上で1〜3秒保持して離すと溜め通常。通常1発分の蓄積と強い吹っ飛び、3秒は現在のメイン足場の端付近まで。保持中は自動発動しない。傾き・沈み・色と紙片は表示だけで、実際の位置と判定は沈まない。
- 空中は方向によらずニュートラル1種類。入力した方向に移動しながら通常の重力で落下する。下入力の急降下も通常どおり。命中時の共通ヒットストップは残る。
- 通常同士の有効判定が同じtickに重なると相殺。双方の攻撃が中断し、短い停止と硬直、衝突光とSEが出る。発生前・硬直中の攻撃は相殺に参加しない。通常の飛び道具も対象。同じ攻撃が何度も相殺やダメージを起こさない。

## 特殊と超必殺

特殊は方向によらず本人のニュートラル特殊1種類。千鶴はおにぎり投げ。旧横／上／下特殊や方向空中技のデータと絵は予備として残すが、現在の入力からは選択しない。透真の銃通常／ドローン特殊／ロケット超必殺など、新しい9人固有技の置換はR3。

練習は開始直後から両者の超必殺ゲージ満タン、使用回数無制限。保持だけで自動連発せず、各攻撃の終了後に新しく押す。練習終了・通常対戦では通常のゲージと回数制限へ戻る。
