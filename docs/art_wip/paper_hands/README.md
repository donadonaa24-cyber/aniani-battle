# 千鶴の手元の確認資料

旧版を使った5枚の手元一覧PNGは、修正前画像を残さないユーザー指定に従って削除した。現在ゲームで使う原画はart_source/paper_cutout/review-catalog.jsonとイラスト確認/千鶴/01_ゲームで採用済み/で確認する。Unityの表示画像はdocs/screenshots/paper_chizuru_all_unity/。

原画の手元を確認するための拡大切り出し。左右の欄は本人の右手／左手を自動判定したものではない。肩と腕の所属は元の全身画像も見て判断する。ゲーム用原画は変更していない。持ち手／親指／甲と掌／指／手首を確認する。
