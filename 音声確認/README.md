# 現在ゲームで使用する音

「現在ゲームで使用中」に、実Unityの合成関数と同じ設定から出力した試聴WAVを保存する。旧試作との混在を避け、このフォルダの4曲と効果音を現在の版として確認する。

- [01 紙の舞台、開幕！](現在ゲームで使用中/01_紙の舞台、開幕！.wav)：メニュー。木琴・弦を弾く音・温かな和音。
- [02 青い都市のパルス](現在ゲームで使用中/02_青い都市のパルス.wav)：星の終わり。ベル・電子プラック・低音。
- [03 駒たちの大立ち回り](現在ゲームで使用中/03_駒たちの大立ち回り.wav)：推し駒Battle。五音音階の弦・太鼓・木の打音。
- [04 文化祭キッチン・ラッシュ](現在ゲームで使用中/04_文化祭キッチン・ラッシュ.wav)：Battle à la carte。鍵盤・軽いリード・調理器具風の打音。
- [05 効果音一覧](現在ゲームで使用中/05_効果音一覧.wav)：通常→特殊→ガード→ジャスト→反撃→ブレイク→三段目→超必殺→KO→場外→カウント→メニュー移動→決定→戻る→縮小→風切り→FIGHT→TIME UP→リザルト。

効果音フォルダには個別19音も保存する。全て本作用の新規PCM合成。音声一覧.jsonに各ファイルの長さ・ピーク・RMS・SHAと生成元を記録する。実装／数値検証と、ユーザーの音楽的な好みの最終確認は分ける。
