# 蓮の攻撃原画

現在は14ユニーク原画を使用。通常1・2段は同じ頭突き2枚、3段は両足蹴り2枚。上／下／空中N／飛車特殊／飛車超必殺は各2枚。現在版はmanifest.jobs、採用先はreview-index.json、証跡はadoption.json。rework_r4_ren_2全4工程合格。

内蔵image_genで本人の待機から生成。元画像と全条件を保持し、preparedは透明移動だけ。pixel-audit.jsonは枠内RGBA・支点・再サンプル0を監査。枠外alpha1ノイズ16画素は除外、元PNGは保持。人物と変身した駒の部位審査は分け、耳・靴の投影の微差、美術最終承認待ちはpart-review.jsonに記録。移動・溜め・被弾まで完成したとは呼ばない。
