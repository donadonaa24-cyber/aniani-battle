# ART1 原画と生成履歴

ユーザー提供の私服設定画2枚と採用済みidleを参照し、内蔵image_genで千鶴の原画を生成しました。API/CLI経由の生成、外部パッケージ取得はしていません。各呼び出しの参考画像は同じ3枚です。第三者ファンアートは生成入力・Assets・原画に含めていません。

- `raw/chizuru/`：26ストリップ。23キャラアニメ＋3小物。idleは承認済み画像の完全コピー。
- `chizuru.manifest.json`：フレーム数・fps・ループ・アンカー・状態対応表・加工設定。
- `generation-log.json`：プロンプトと生成履歴。新規採用26枚（ストリップ25＋私服カットイン1）、作り直し10枚、ツール出力計36枚。
- `rejected/chizuru/`：不採用の10版をローカル保存。Git管理外、Unity外。

超必殺は6枚版で横方向の重なりと小さな体格が発生したため、指示書の目安6枚から **4枚** へ変更。予備動作→鍋を掲げる→右へふるまう→戻すを維持し、持続時は2番の絵（0始まり）を使います。他の枚数は指示書の目安通りです。

原画は合計約38.01 MiBです。再生成の中間版を含めると増えるので、配布にはUnity内の加工済みPNGと生成アニメセットを使ってください。正確な現在サイズとSHA-256は `docs/art_wip/chizuru_inventory.json` に記録します。
